# 20260430-dsc-tech-talk
Presentation materials from the LaTeX lightning talk held at the Okayama University DS Club

岡山大学DS部で行われた，$\LaTeX$ハンズオンの講演資料です。
30分を目安に作っています。

## 使いかた
この資料は，Slidevで作られました。
Slidevの環境を整えた上で，`slide.md`があるディレクトリで`npm run dev`を実行してください。
ローカルサーバーが立ち上がり，スライドを表示できます。
